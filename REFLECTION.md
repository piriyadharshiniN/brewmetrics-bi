# Project Reflection

During this project, I learned how to build a Business Intelligence solution using Power BI, GitHub, and GitHub Copilot. I imported the BrewMetrics sales dataset and organized it into a fact table and three dimension tables: Dim_Date, Dim_City, and Dim_Product. Creating relationships between these tables helped me understand data modeling and how a star-schema-style structure supports analysis.

I created DAX measures to calculate total sales, month-over-month growth, running total sales, item sales ranking, and average sale value. I also developed dashboard visuals to compare sales across cities and products and analyze Cold Brew sales over time. A city slicer and date hierarchy made the report interactive.

GitHub Desktop helped me track project changes through commits and maintain version control. GitHub Copilot assisted me in drafting and reviewing DAX formulas and project documentation, while I checked the results in Power BI.

One challenge was ensuring that the measures and dashboard changes were saved correctly in the Power BI project files. This taught me to verify saved files instead of relying only on what appears in the application.

Overall, this project improved my understanding of data modeling, DAX, dashboard design, and version control. I also learned how AI coding assistance can support BI development while requiring human verification.
